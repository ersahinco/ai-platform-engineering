# Claude Code Compatibility Entry Point

## Canonical Repo Policy

Use [AGENTS.md](./AGENTS.md) as the single steering document for shared repository policy:

- repo structure and ownership
- branching and commit conventions
- DCO and AI attribution rules
- quality gates
- coding expectations

If `CLAUDE.md` and `AGENTS.md` ever disagree, follow `AGENTS.md` and treat this file as stale.
